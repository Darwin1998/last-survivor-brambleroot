# Changelog

## 2.0 — The Last Survivor vertical slice

- Rebranded Brambleroot with Darwin's stranded-world premise.
- Replaced the one-file game with separate data, rules, save, engine and UI modules.
- Expanded the fixed clearing into a 2,100 × 1,600 scrolling wilderness with six regions and fog of war.
- Added five interconnected survival stats, inventory weight, weather and consequences.
- Added Analyse, the rank-locked Online Shop, quests, Credits, XP, levels and ranks.
- Added mobile touch movement and responsive game panels.
- Added versioned autosave, backup recovery, manual save and save deletion.
- Added automated tests for progression, purchases, crafting, quest rewards and state serialization.

## 2.1 — Pixel-art visual overhaul

- Added a true world-to-screen camera zoom with bounded, smooth following and keyboard zoom controls.
- Rebuilt Darwin as a large animated directional character with idle, walking and tool-use poses.
- Replaced geometric trees and rocks with multi-layer procedural pixel art at readable scale.
- Added dense ground details, flowers, dirt paths, shadows and multiple foliage variations.
- Rebuilt the river with irregular animated water, natural banks, pebbles, ripples and a collision-safe bridge.
- Added harvesting shake, particles and screen impact tied to actual gathering actions.
- Reworked clock-based lighting for bright daylight, warm evenings and readable blue nights.
- Enlarged every HUD, menu, status bar, button and objective for desktop readability.
- Added eight illustrated hotbar slots and procedural item art across inventory, crafting and the Shop.
- Corrected responsive Canvas sizing so Android layouts retain proper sprite proportions.
